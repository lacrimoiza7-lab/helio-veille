helio-veille

Ma station météo spatiale qui ne dort jamais

Le problème

Ma station Helio-Watch enregistre le vent solaire, le champ magnétique, les aurores et les séismes…

… mais seulement quand mon PC est allumé. PC éteint = trous dans l'historique.

Ma demande à Claude

« Que la collecte continue toute seule,
même quand mon ordinateur dort. »

La solution : un robot dans le cloud

Un robot gratuit de GitHub lance le script collecte.py toutes les 4 heures.

Il va chercher les mesures officielles (NOAA, USGS) et les range dans le dépôt.

Nos décisions

  • ☁️ Collecte dans le cloud, pas sur mon PC
  • 🧮 Aucune IA dans les mesures : un simple script recopie les sources
  • 🛰️ ISS exclue : un point toutes les 4 h ne fait pas une trajectoire
  • 🤖 La synthèse IA du ciel profond (veille.json) est rangée à part

L'astuce des fenêtres

Chaque source rend les 6 à 24 dernières heures. Les passages se chevauchent :

on garde une mesure par minute, les doublons sont ignorés, et un passage raté ne coûte rien.

Ce que Claude a produit

  • 🐍 collecte.py : le script de collecte
  • ⚙️ collecte.yml : la tâche planifiée
  • 📁 mesures/ : un fichier compressé par jour et par source
  • 📖 README : l'explication de tout le projet

Le résultat

0

mesures de vent solaire reçues au dernier passage

Le système tourne seul, 6 fois par jour. Mon PC peut dormir : le Soleil reste surveillé ☀️
